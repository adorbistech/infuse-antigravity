## Integration

The plugin connects Antigravity to the existing INFUSE Remote MCP service and installs the INFUSE governance skill.

No credentials are included in the plugin.

## Validation

Before submission verify:

* plugin manifest parses correctly
* MCP configuration points to the production INFUSE endpoint
* governance skill is present
* README is complete
* SECURITY.md is present
* PRIVACY.md is present
* LICENSE is present
* no secrets are committed
* repository points to `adorbistech/infuse-antigravity`
* Antigravity successfully discovers the plugin
* INFUSE MCP tools are available after installation
